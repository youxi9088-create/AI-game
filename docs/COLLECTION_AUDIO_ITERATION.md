# DressBattle 0.9.0-rc.1：主动写真与音频事件迭代

基线：youxi9088-create/AI-game，main 831b76b03adc21c41780b0a2721a984dbab8b9eb。
核对日期：2026-10-02。另一个同名 DressBattle 仓库是早期快照。AI-game 包含线上同一产品完整工程，但 main 还有结算、视频和工坊修复尚未在线上出现，发布前必须核对这些既有差异。

## 已实现

- 首屏说明胜利与写真收集关系；不可购买、转赠或提现的 Token 声明。
- 胜利演出后进入写真工作室：仅选该牌友已解锁服装，两个背景底色、三种滤镜、两种构图、24 字作品名、保存和 PNG 分享图。底色是照片衬底，不替换原素材里的场景；构图是裁切，不伪造新姿势。没有接入额外图片生产。
- 一场获胜最多一份作品；再次保存更新同一份。跳过/刷新后可以从写真馆的待定格列表继续。现有卡册、演出、动态视频、角色生产和平台回传保留。
- 服务端校验胜利资格、角色与已解锁服装，忽略客户端提供的图片路径和胜场等字段。
- 每次牌友作为胜利奖励登台 +10 羁绊；30/60/100 阈值开放新的羁绊文字；1/3/6 款收藏自动获得称号。下一套服装按现有确定顺序展示。旧版收藏保留，不臆造历史羁绊。
- 修正农民队友先出完牌时玩家也应获胜；finisherId 单独保存实际出完牌者。
- gallery.json 从 v1 兼容读取、写入 v2；卡册、奖励资格、作品和羁绊共用一次原子文件替换。损坏文件阻止启动，避免以空档覆盖。
- 音频事件统一入口；单张/对子/三张类/顺子/炸弹/王炸差异音色，AI 降音量，服装与定格反馈；首次点击解锁音频，分组音量持久化，后台暂停，减少动态不再等同静音。合成音同时最多 24 声，播放结束回收节点。
- FMOD 接口适配器使用 getEvent → EventDescription.createInstance 输出对象模式，含播放失败时实例释放。事件层提供 TableTension、PerformanceReveal、VideoPlaying 参数。

## 明确未完成的部分

音频当前仍使用合成试听后端。仓库没有获授权的 FMOD HTML5 SDK、Master/strings/UI/SFX/Music/VO Bank、配套录音和分轨。正式 FMOD、自适应音乐可闻分层、小节量化、空间混响、VO、随机多采样和移动端 DSP/内存预算未验收；不宣称已满足音频设计 v1.0 的正式验收。

FMOD 集成：宿主用自身获授权 SDK 初始化 Studio System 并加载 Bank，调用 createFmodBackend(studio, { resume })，再 installAudioBackend(backend) 和 backend.startMusic()。Bank 必须提供 bus:/、bus:/SFX、bus:/UI，事件见 sfx.js，三个全局参数见上一节；音乐与转场在 Studio 工程内配置。宿主 resume 必须在真实手势内恢复实际 SDK 音频上下文。适配器测试仅验证 API 合同，不替代真实 SDK/Bank 集成测试。

未添加新牌种、残局、排行榜、好友访问、新姿势/表情素材或场景图。AI 性格、规则库、完成度、卡面升级和回放在基线中已有，不重复创建。

当前服务沿用已有单一 player 存档/钱包模型，本迭代没有把它改造为多用户账号服务。上线到多人公网前应确认部署隔离方式；本次测试不代表跨用户隔离通过。

## 验证

- npm run lint：JS 语法检查（项目的 typecheck 同为语法检查，不是静态类型分析）。
- npm test：规则、AI、收藏迁移、幂等、解锁防伪和 FMOD 适配器回归。
- npm run build：现有构建边界文件检查，无打包编译步骤。
- PLAYWRIGHT_CHANNEL=bundled npx playwright test tests/e2e/collection-loop.spec.mjs
- 可用 PLAYWRIGHT_EXECUTABLE_PATH 指向已安装 Chromium。本环境标准下载失败，使用临时安装的 Chromium 执行，未改项目依赖。
- E2E 从真实规则 API 完成胜局，再通过浏览器执行编辑、保存、刷新、PNG 导出、移动端布局与音量记忆。不是以伪造胜利快照代替结算。

## 发布与回滚

尚未发布 yyxx101.online。仓库无 Actions 发布记录，当前没有服务器管理连接。不能仅依据域名推断生产工程目录或服务重启命令。

部署前备份实际 GALLERY_STATE_PATH 和 TOKEN_STATE_PATH，保留现网角色资产、工坊任务状态与密钥配置；不要用仓库中的示例/测试存档覆盖运行数据。先在独立预生产目录用该分支启动，复核源版本差异并跑上述验证。生产开启 NODE_ENV=production，确认禁止指定 seed 与检查器入口。

回滚必须配套保存 v2 收藏档副本；旧代码再次保存会丢失 collection 字段，不能把它视为无损兼容回滚。保留原始 v1 备份与升级后的 v2 备份分别用于旧版/新版恢复。钱包与卡册的跨文件事务、整局服务重启恢复仍沿用基线限制。
