# UGC 角色资源目录规范

当前权威目录：`apps/web/assets/pals/ugc/<角色名>/`。

- `甜美卷发小甜甜/`：完整的自定义角色资源。
- `墨鸢/`：完整的自定义角色资源。
- `星恒/`：当前 v103 资源与用户交付的源视频。
- `代娜/`：代娜的图片、动作源、透明动作 WebM 与换装演出；主资源使用 `daina-`，第二套经人工核验的资源使用 `daina-alt-`，不再使用旧计划编号。
- `甜美卷发小甜甜/`：小甜甜的透明五态动作与从已核验动作视频抽取的展示图；第二套动作使用 `xiaotiantian-alt-`。
- `米娅/`、`银岚/`：官方角色的 UGC 补齐资源。
- `_archive/`：已删除生产计划的历史资源，不进入当前运行时。
- `_backup/`：人工修复前的可恢复备份。
- `_quarantine/`：无法归属或损坏的残留文件，不进入运行时。

约束：

1. UGC 根目录不得直接存放资源文件。
2. 已确认角色的所有 UGC URL 必须位于与角色名字一致的一级目录。
3. 新生产资源由服务端按角色名自动写入对应目录，文件仍保留计划 ID 以避免同名版本覆盖。
4. 删除计划的资源只能进入 `_archive/`，空壳或无法追溯的文件进入 `_quarantine/`。
5. 执行 `npm run verify:ugc-assets` 校验目录归属、角色目录嵌套、缺失引用与代娜旧编号回归。
