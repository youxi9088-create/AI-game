# 换装斗地主桌面端 UI/UE 改造明细

> 评估依据：UI/UX Pro Max Skill + 当前工程实际页面验收。
> 
> 评估范围：桌面端浏览器，优先验证 1280×720 及以上尺寸；移动端暂不纳入本轮。

## 一、全局 UI 规范

### 1. 统一设计 Token

统一放入 `apps/web/styles-overrides.css`，避免页面继续散落使用颜色值：

```css
:root {
  --bg-page: #080c14;
  --bg-surface: #101827;
  --bg-surface-raised: #172235;
  --bg-surface-soft: #202b3d;

  --text-primary: #fff8eb;
  --text-secondary: #d8d1c5;
  --text-muted: #aaa396;

  --gold: #e8bd68;
  --gold-strong: #f4cf7e;
  --purple: #8c68ef;
  --success: #62d49d;
  --warning: #e3a34c;
  --danger: #db6975;
  --line: #d6b66c42;

  --space-1: 8px;
  --space-2: 16px;
  --space-3: 24px;
  --space-4: 32px;
  --space-5: 48px;

  --radius-sm: 8px;
  --radius-md: 14px;
  --radius-lg: 22px;
}
```

### 2. 字体层级

- 页面标题：40–48px，700–900
- 区块标题：20–24px，700
- 卡片标题：16–18px，700
- 正文：14–16px，400–500
- 辅助说明：12–13px
- 状态标签：11–12px，600–700
- 正文行高：1.5–1.7
- 各页面使用同一套字号和语义颜色。

### 3. 按钮规范

- 主按钮：金色或紫色，每个区域只保留一个主要动作。
- 次按钮：深色描边。
- 危险按钮：红色边框和红色文字。
- 禁用按钮：降低透明度、取消 hover、禁止点击。
- 桌面端按钮高度至少 40px。
- 所有按钮具备 hover、focus、pressed 状态。
- 删除、打回等危险动作必须二次确认。

## 二、大厅 `#/home`

### 主视觉

当前问题：背景、角色、标题和 CTA 的层级还不够稳定；Token 说明偏弱。

修改要求：

- 保留深午夜蓝 + 香槟金方向。
- 中央标题作为唯一最大视觉焦点。
- 两侧角色增加独立暗色渐变保护层。
- Token 余额改为更醒目的状态徽章。
- “进入今晚牌局”作为唯一主 CTA。
- “创建虚构牌友”作为次级 CTA。

验收：1280×720 下标题、角色、牌友选择卡和按钮不重叠，Token 信息清晰可读。

### 牌友选择器

- 选中牌友使用金色边框和状态标识。
- 官方牌友、自定义牌友使用文字区分，不能只依靠颜色。
- 头像加载失败显示统一占位，不显示浏览器破图。

## 三、牌桌 `#/table`

### 牌桌布局

当前问题：背景较强，牌区和状态文字不够突出，座位信息分散。

修改要求：

- 增加稳定的深色牌毡/桌面层。
- 牌桌中心建立明确的出牌区。
- 顶部放局数、地主和阶段；中央放出牌与等待提示；底部放手牌和操作。
- 头像、剩余牌数、角色身份和气泡统一成座位组件。
- 所有座位使用统一头像尺寸和文字间距。

验收：牌桌背景不干扰牌、状态和按钮；当前出牌人一眼可识别；“等待你领出”“轮到你出牌”“对方思考中”有明显区别。

### 手牌交互

当前问题：1280×720 下手牌压缩并重叠，点击边界不清楚。

修改要求：

- 视觉重叠与点击热区分离。
- 每张牌保留至少 44px 的独立点击区域。
- 选中状态同时使用上移、金色边框和高亮。
- 不可操作状态使用灰度、禁用鼠标和明确状态文字。
- “提示”“不出”“出牌”按操作优先级排序。
- 键盘 Tab 可以访问每张牌。

验收：17 张牌均可独立点击，不会误点相邻牌，选中牌不被遮挡。

### 牌桌资源映射

| 用途 | 资源字段 |
| --- | --- |
| 头像 | `avatarRef` |
| 牌桌立绘 | `tableStandeeRef` |
| 五态动作视频 | `actionPack.A01-A05` |
| 动作视频失败回退 | `actionImage.A01-A05` |

不得把大厅立绘、头像或卡面直接复用到牌桌槽位。

## 四、结算与视频演出

### 结算流程

```text
牌局结束
→ 结算画面
→ 判断玩家胜负
→ 玩家胜利：选择 AI 牌友
→ 播放对应牌友的换装演出视频
→ 掉落对应写真卡
→ 写入写真馆
→ 下一局 / 返回大厅

玩家失败
→ 结算画面
→ Token 扣减
→ 不播放演出
→ 下一局 / 返回大厅
```

要求：

- 结算先显示输赢和 Token 变化。
- 胜局按钮显示具体牌友名称，例如“林星将为你跳舞”。
- 输局不能出现“继续演出”暗示。
- 输局直接提供“再开一局”或“返回大厅”。

### 视频弹窗

- 使用无边框大画面。
- 竖屏视频使用背景模糊补边，主体不裁切。
- 提供播放、暂停、进度、静音和全屏。
- 加载失败显示原因、重新加载和跳过演出。
- 关闭按钮固定在右上角。
- 底部说明不遮挡人物主体。
- 结算演出和写真馆回放采用统一控件样式。
- 自动播放只用于明确进入的演出场景。
- 支持 `prefers-reduced-motion`。
- 关闭后恢复原触发按钮焦点。

### 视频版本绑定

每条视频必须绑定：

```text
palId
outfitId
danceId
videoRef
posterRef
version
```

如果视频和卡面不是同一 `outfitId`，前端不得播放，显示“资源版本不一致”。

## 五、写真馆 `#/gallery`

### 卡面网格

- 所有卡面统一 3:4 比例。
- 已解锁、未解锁、升级卡使用统一卡框。
- 图片加载失败显示标准错误卡。
- 未解锁卡不能显示可识别的人物和服装细节。
- 卡面标题、角色名、动作名统一排版。

### 筛选器

- 保留：全部、林星、米娅、银岚、自定义牌友、新获得、金框、缺失。
- 选中状态同时使用边框、背景和 `aria-pressed`。
- 显示当前筛选结果数量。
- 无结果时显示说明和清除筛选按钮。

### 卡面详情浮窗

- 图片和信息区域比例固定。
- “回看跳舞”使用主色。
- “导出卡面 PNG”使用次级色。
- “关闭”使用中性色。
- 支持 Esc 关闭、点击遮罩关闭、键盘左右切换。
- 关闭后焦点回到原卡片。

### 回放视频

- 标题显示角色名 + 卡面名。
- 视频失败提供重新加载。
- 无视频时显示“该卡暂未配置视频”，不能显示黑屏。
- Poster 必须和当前卡面属于同一服装版本。

## 六、牌友工坊 `#/workshop`

### 页面结构

```text
创建牌友表单
资源计划列表
生产任务 / 可确认资产
```

- 资源计划默认只展示列表行。
- 生产任务默认折叠。
- 资源计划详情通过浮窗打开。
- 详情浮窗内部滚动，不撑开页面。
- 可确认资产单独展示。

### 资源计划列表

每行显示：

- 牌友名称
- 计划 ID
- 版本
- 资源数量
- 当前阶段
- 状态
- 查看详情按钮

统一状态：

- 待生成
- 角色资料卡生产中
- 等待确认资料卡
- 生产中
- 需重产
- 已完成

“查看详情”使用中性色，不使用主 CTA 紫色。

### 资源计划详情浮窗

结构：

```text
浮窗标题
计划身份
生产阶段进度
角色资料卡确认区
视觉风格约束
资源列表
资源生产路由
失败原因
重试 / 打回 / 删除操作
```

要求：

- 外层高度固定，内部内容区滚动。
- 打开详情不会撑开主页面。
- 关闭后恢复页面滚动位置。
- 标题区固定。
- 删除按钮固定在右上角并使用危险色。
- 生产中的计划不可删除。

### 生产任务列表

每条任务必须展示：

```text
任务名称
资源计划名称
资源计划 ID
牌友名称
版本
资源槽位
生产路由
Provider
任务状态
```

失败任务展开后直接显示：

- 失败原因
- Provider 返回信息
- 尝试次数
- 最近一次时间
- 重新生产
- 打回重产
- 删除任务记录

### 资源状态

| 状态 | 颜色 | 文字要求 |
| --- | --- | --- |
| 生产中 | 黄色 | 必须显示“生产中” |
| 成功 | 绿色 | 必须显示“已完成/已取回” |
| 失败 | 红色 | 必须显示“生产失败” |
| 待确认 | 紫色 | 必须显示“待确认” |
| 锁定 | 灰色 | 必须显示“确认资料卡后解锁” |

状态不能只依赖颜色。

### 角色资料卡确认节点

```text
01 生成角色资料卡
02 用户确认角色资料卡
03 生产其余资源
```

确认前：

- 其他资源全部锁定。
- 不提交下游 Provider。
- 明确提示确认后才会继续生产。

确认后：

- 显示资料卡版本。
- 显示 SHA-256 前缀。
- 显示公网 URL 已就绪。
- 所有下游资源显示引用的资料卡版本。

## 七、图片展示与失败回退

统一映射：

| 资源 | 使用位置 |
| --- | --- |
| `avatarRef` | 大厅选座、牌友头像 |
| `loungeStandeeRef` | 大厅主视觉 |
| `tableStandeeRef` | 牌桌座位 |
| `masterPortraitRef` | 工坊确认资料卡 |
| `outfitLayerRef` | 写真卡面 |
| `outfitFxRef` | 卡面特效层 |
| `actionImage.A01-A05` | 动作视频失败回退 |
| `posterRef` | 视频封面和视频失败回退 |

所有图片组件统一支持：

- 加载中占位；
- 加载失败占位；
- 描述性 alt 文本；
- 点击查看大图；
- 不显示浏览器原生破图图标。

## 八、动效与异步反馈

- 按钮反馈保持在 80–150ms 内。
- 弹窗使用淡入 + 轻微缩放。
- 退出动画短于进入动画。
- 卡片悬停只做轻微上移或边框变化。
- 不动画改变布局尺寸的属性。
- 生产任务显示提交中、已提交、生产中、失败、可重试、已完成。
- 请求期间禁用按钮，防止重复提交。

## 九、桌面端验收标准

### 大厅

- 1280×720 下标题、角色、选择卡和 CTA 不重叠。
- 主 CTA 层级唯一。
- 角色资源映射正确。

### 牌桌

- 叫分、出牌、不出可完整操作。
- 每张手牌可独立点击。
- 牌桌立绘不遮挡牌区。
- 动作视频失败时显示静态回退。

### 结算

- 玩家赢：先结算，再播放对应牌友视频，再掉卡。
- 玩家输：只结算，不播放视频。
- Token 变化清晰。
- 视频失败可重试或跳过。

### 写真馆

- 卡面正常显示。
- 回放可打开、暂停和关闭。
- 导出 PNG 可用。
- 关闭后回到原卡片。

### 牌友工坊

- 资源计划列表不撑开页面。
- 详情浮窗内部滚动。
- 任务和计划明确关联。
- 失败任务可以重试和打回。
- 资源图片失败有明确状态。
- 角色资料卡确认前后流程正确。
