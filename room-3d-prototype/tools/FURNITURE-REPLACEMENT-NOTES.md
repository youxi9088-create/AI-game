# 同资源包家具替换

## 本轮约束

用户修正：不是整个资产库混选，而是家具所属的同一套资源包。Interior 1 可选其 1580 个资源；Goodies Cozy 可选其 302 个资源。家具类别只是可清空的筛选，不限制同类。程序生成家具、AI 生成物件没有资源包归属，保持可移动但不开放跨包替换。

后续扩展：Interior 和 Goodies 的墙、地板、窗户注册独立固定编辑ID。点击打开面板；拖动建筑面继续旋转视角，不移动建筑。建筑仅同包同类型替换，模型按安装槽各轴适配（区别于家具等比缩放），地板保持顶面高程，重复替换保持原槽和朝向。原始独立地板拾取平面保留，新地板三角形标记 placementFloor。Interior 小写 wall_* 是水平装饰板，不作为直立墙候选。

建筑面板可应用纯色涂装或恢复当前模型原材质。使用独立材质克隆，纯色涂装关闭原色贴图以避免色板叠乘偏色，几何细节保留。只改选中的一块，不批量覆盖整屋。颜色与替换文件合并存档，单独改色不要求替换模型；颜色选择失败/取消不修改现场。原先浅墨绿地板在未编辑时保持不变；恢复原材质回到当前模型的初始材质。

流程：进入屋内 → 点击家具（位移小于4像素）→ 同包资源面板 → 搜索/分类 → 3D预览 → 确认替换。按住拖动仍为移动，取消指针不打开面板。原生 dialog 提供模态焦点和 Escape 退出；预览可旋转。沿用当前米白/灰绿配色和既有 asset-catalog 分类，不引入第三方 UI 美术。

加载清单或模型失败保留旧家具，支持重试。文件名经所属包清单校验，拒绝跨包和未知路径。替换保留根节点、位置、朝向、稳定ID和放置模式，新模型等比适配原家具最大尺寸；不假设不同类别仍具有相同物理用途。桌面摆件需能命中新模型向上表面，否则拒绝并提示先挪开。家具材质不与浅墨绿地板材质共用。

替换选择单独保存至 hidden-object-furniture-replacements-v1，位置继续使用既有位置存档。异步恢复时暂不允许拖动正在恢复的那件家具；失败保留默认模型并提示。旧模型三角形从房屋及全局支撑面列表移除，新模型表面重新注册。两层地板拾取不变。

## 验证与限制

node tools/test-furniture-replacement.mjs：清单数量及同包范围、跨包/未知文件拒绝、加载失败不变、预览不修改场景、等比/位置/朝向、旧支撑面清除及新表面注册、存档选择重新加载、损坏存档降级。

node tools/test-interior-room.mjs：复式及 Goodies 既有几何、家具、支撑、地板颜色隔离回归。npm run build 检查生产构建。

node tools/test-architecture-editing.mjs：两包墙/地板/窗户固定编辑项，颜色隔离与原材质恢复、类型限制、重复替换槽尺寸与侧墙朝向、地板射线和颜色元数据读回。界面点击及刷新完整路径仍待浏览器实测。

证据状态为“已实现待界面验证”。浏览器访问先前被安全策略阻止，未绕过限制；本轮没有真实界面点击/拖动截图证据。未宣称已通过视觉验收；外部竞品对标本轮也未新增核验。未发布公网。
