# 3D 小屋原型：寻物关卡与微缩街造物间

## 当前版本与公开仓库说明

以下为当前版本说明；后面的初始原型记录只保留作历史背景。

- 当前为四个家：植物客厅、暖木厨房、Interior 双层小楼、Goodies 房间。
- 小镇地面已扩展至原面积 3 倍，含公共设施及 8 块预留空地；尚不支持空地建房。
- 支持摆放、移动、选中反馈、角度调整、移除，以及同一资源包内的家具替换。
- 墙壁和地板可改色或分类替换；窗户、窗帘和其他墙面挂件可编辑，挂件可换墙并随墙转向。
- 摆放数据存储在当前浏览器 localStorage。没有完整的碰撞检测或撤销系统。

### 素材恢复（重要）

公开仓库仅包含自有代码、转换工具和文档，不含 Unity 商城原包、模型和贴图。用户提供资源不代表已验证公开再分发许可；未经授权不要上传这些素材。

完整体验需要用合法授权的原包恢复以下目录，每包保留 catalog.json、GLB 和配套贴图的相对路径：

| 目录 | 原包 | 本地模型数 |
| --- | --- | --- |
| `public/content/interior-1/` | Interior 1 v1.0 | 1580 |
| `public/content/low-poly-rooms/` | Low Poly 30 Rooms Interiors 1000 Objects | 1168 |
| `public/content/goodies-cozy/` | Goodies Cozy Room Pack 1.2 | 302 |

已有转换产物可直接恢复到上述目录；重新转换见 [转换说明](tools/UNITY-ASSET-CONVERSION.md) 和 [Goodies 接入说明](tools/GOODIES-ROOM-NOTES.md)。这些文档含历史阶段记录，当前功能以本节为准。缺少素材无法完整显示导入的小屋及资产库，构建成功不代表素材齐全。

### 运行与后端

本目录与仓库根目录项目独立。进入本目录后运行 `npm ci`，再运行下文启动命令。建议 Node.js 22.12+。第一关为 `/`，四个家的小镇为 `/?level=2`，模型库为 `/asset-preview.html`。

`vite.config.js` 将 `/api/room-object` 代理至 `http://127.0.0.1:5174`。AI 功能需另外运行提供此接口的服务端，本目录不包含服务端实现或密钥。部署时需自行配置后端及同源路由，不要把服务端密钥放入前端。AI 输出基础几何体组合，并非任意高精度模型。

### 验证状态

已进行构建及结构/逻辑回归，浏览器工具访问受限，尚未完成本轮界面目视验收。模型回归需要先恢复素材。可运行 `npm run build` 和 `tools/test-*.mjs` 下的脚本；上墙资产筛选结果不等于逐项人工审核。

## 运行

```powershell
npm install
npm run dev -- --port 5175
```

访问 `http://127.0.0.1:5175/`。拖动旋转、滚轮缩放、点击 8 个藏物；找到后对应 3D 物件会从场景中消失。顶部「导出 GLB」可以下载包含全部物件的原始房间模型。

## 第二个试验关卡：三个家的微缩街

先在相邻的 `hidden-object-story-game` 工程中运行 `npm run dev -- --port 5174`，等待 F 开发环境的服务端同步完成，再打开 `http://127.0.0.1:5175/?level=2`。

第二关是原创的暖木、奶油色、鼠尾草绿微缩街场景：林家是植物客厅，陈家是暖木厨房，周家是晴蓝画室。先在街景选择一家，再输入一句话。服务端使用已配置的 AI Gateway 任务生成**可验证的 3D 几何结构**；成功后显示模型缩略图和名称，可从物品栏拖到当前家的地板、桌面或架上。也可以单击物品卡快速摆放，再拖动调整位置。切换家庭时只显示该家的摆放结果；回到街景可同时查看三家。物件、所属家庭与位置保存在当前浏览器的 localStorage，刷新后保留。顶部「导出 GLB」可导出整条街和三个家的已摆放物件。

这不是高精度任意网格生成：AI 负责设计由基础几何体组成的卡通 3D 道具，浏览器按结构生成真正的网格。若 AI 服务不可用，页面明确报错，不会用预制道具冒充生成结果。

## 边界

- 这是独立风格与玩法原型，尚未接入现有五关，也未部署到线上。微缩街提取了参考产品的温暖材质、开放房间和自由摆放方向，但没有复用其图片、模型或 UI 资产。
- 模型由 Three.js 基础几何程序化制作，适于检验视角、构图与交互；正式关卡还需提升道具造型、材质细节、遮挡逻辑和性能。
- 导出的 GLB 包含房间与道具几何及材质，不包含网页 HUD、拾取事件或运行时光照。
