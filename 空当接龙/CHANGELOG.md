# Changelog

## 0.7.2 - 2026-09-15

- 花色颜色约定修复：扑克牌基本规则（黑桃/梅花=黑、红桃/方块=红）此前会被主题氛围染色破坏。两层修复——① 生成端：suitMotif prompt 按花色指定纯黑/纯红填充并移除主题氛围注入（主题词正是染色的诱因）；② 渲染端：tintSuitMotifs() 用 canvas 把 4 张花色符号重染为主题 palette 的 redSuit/blackSuit（边缘 alpha 渐变、透明背景 PNG），存量主题立即生效，实测颜色与文字角标完全一致（#c72f3d / #1d2730）。
- 花色符号“脏图拒绝”：部分生成图画成泼墨式大色块（墨迹占比 >50%），重染后会变成牌面污渍，自动弃用该图并回退文字花色符号。
- 点数字形视觉大小归一化：AI 生成的 13 张 A-K 字形图各自墨迹占比存在随机偏差（实测 78%~88%），导致同屏牌面数字大小不一。主题应用与页面启动时用 canvas（512px、亮度阈值 245）逐张测量字形墨迹高度，按 85% 统一基线计算缩放系数（glyphScale，clamp 0.8~1.3），渲染时以内联样式缩放对齐，实测 13 个字符渲染高度极差从 17.6px+ 降至 3.2px。字形基准尺寸以 CSS 变量 --glyph-size（默认 1.15em，对标内置主题文字数字观感）统一控制，结果随主题包持久化、跨刷新不重测、失败自动回退不影响渲染。
- 修复 styles.css 中残留的旧字形尺寸规则（26px×24px + contain，会与新基准冲突且 contain 导致字形各自缩放不一）。
- 服务端清理：批量删除 69 个历史降级/空壳主题（「定制经典主题」5.3MB dataUrl 内嵌包 ×17——被"从服务端恢复"拉入会超出 localStorage 5MB 配额导致 persist 静默失败、「水墨山水主题」空壳 ×52）。
- 测试与诊断：e2e mock 从 1×1 像素升级为程序化 8×8 白底黑心 PNG（tests/e2e/helpers/test-png.mjs，符合干净剪影特征）；浏览器回归 24/24 通过、Node 单测 32/32 通过；新增 scripts/verify-render.mjs（无头浏览器端到端验证主题渲染、字形一致性与花色颜色）、scripts/measure-glyph.mjs、scripts/debug-glyph.mjs。

## 0.7.1 - 2026-09-14

- 修复生成主题背景“变成角色贴纸插画”的问题（如“唐老鸭”主题背景实际生成的是深蓝底+中央唐老鸭贴纸，而非桌面场景）：背景与牌背的图像 prompt 补上硬约束——背景必须是纯环境场景（只允许桌面材质、纹理与氛围光），绝对禁止角色、人物、动物、卡通形象、贴纸、白色贴纸描边与居中主体插画；牌背必须是中心对称的纯纹样图案。
- IP/品牌黑名单改写从“追加式”根治为“剔除式”：此前命中黑名单（如“唐老鸭”“可口可乐”）只在 prompt 末尾追加免责要求，图像模型仍能看到原词并照画（官方 IP 形象外泄风险）；现在先把黑名单词从 prompt 中剔除，再追加抽象化改写要求，文本网关与图像工作流均读不到原词。新增回归断言固化该行为（网关与图像 prompt 不得包含黑名单原词、背景 prompt 必须含禁角色约束）。
- 背景/牌背 prompt 数据源改为 `spec.material`（文本网关输出的抽象材质描述），不再携带主题主体词：实测“水手鸭”等具象主题词会直接导致背景画入角色（原创卡通鸭入画）；同时补“不要绘制白色矩形/面板/卡牌占位区块”（修掉实测出现的中央白色大面板）。新增回归断言：背景/牌背 prompt 必须使用 spec.material 且不含主题主体词。
- 新增 `scripts/dev-api-local.mjs` 本地启动器：固化 PORT=4174（覆盖 hidden-object-web/.env 的 PORT=3001）、AIHUB_POWERSHELL_PATH（本机无 pwsh 7，须用 Windows PowerShell 5.1）等变量，spawn 方式启动 api/server.mjs（直接 import 不会监听端口）。
- 说明：修复前生成的含 IP 形象主题（如唐老鸭套件，12 张头牌与牌背均为官方形象）无法通过 prompt 修复挽回，建议删除后用新流水线重新生成，避免外网发布的版权风险。

## 0.6.1 - 2026-09-14

- 主题库新增“从服务端恢复历史生成主题”入口：工坊生成并通过质量门的主题一直在服务端 SQLite 留档，但本地主题库跟随浏览器 origin，换端口或换浏览器后会“看不见”；现在可在主题库底部折叠区内一键拉回真实流水线（非 Mock）生成的主题，按 themeId 去重、已晋升为内置的红白主题与误恢复主题不重复进入，恢复结果内联展示并写入埋点。
- 主题库新增生成主题删除：非内置、非当前使用中的主题 tile 提供“删除”按钮，确认后同时从本地主题库与服务端存档移除（服务端 404 视为已删），失败时明确提示；内置主题不提供删除且服务端 409 保护，正在使用的主题按钮禁用。
- 新增回归：主题库可从服务端恢复真实流水线生成主题（恢复、去重、跨刷新保留与“无新主题”提示）、可删除生成主题并同步服务端（确认弹窗、内置主题不可删、删除后服务端不再恢复），浏览器回归扩展为 24 条；红白主题视觉基线断言增加 0.5% 亚像素容差。

## 0.6.0 - 2026-09-12

- 主题流水线补齐牌面资产：AIHub 与 OpenAI Provider 在背景、牌背之外，以 5 路并发生成 13 个 A-K 点数字形、4 个花色符号与 12 张 J/Q/K 头牌插画；单项失败只记录原因并回退到程序化字形，不再让整张主题失败。
